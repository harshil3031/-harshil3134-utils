### Added
- `string` — truncate, slugify, titleCase, maskSensitiveData
- `date` — formatDate, timeAgo, isExpired
- `validation` — isValidEmail, isValidURL, isValidPhone, isStrongPassword
- `object` — deepClone, debounce, throttle, groupBy, flattenObject
- `network` — fetchWithRetry, createQueryString, parseQueryString
- `storage` — setWithExpiry, getWithExpiry
- `misc` — generateUUID, copyToClipboard, formatBytes, randomBetween
- Full TypeScript types and JSDoc comments
- Dual CJS + ESM build output
- Vitest unit tests for all modules
